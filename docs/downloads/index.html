On a phone or tablet? These are desktop apps — play in the browser instead.

Windows

  1. Unzip, open the game's folder, double-click the .exe.
  2. If you see “Windows protected your PC”: click More info → Run anyway. The games are free and not code-signed yet, so Windows doesn't recognise them.

Mac

  1. Unzip and drag the app to Applications.
  2. Open it once; macOS will refuse because it isn't signed with an Apple Developer ID yet.
  3. Go to System Settings → Privacy & Security and click Open Anyway.

Not sure which Mac you have? Apple menu → About This Mac: “Apple M…” means Apple Silicon.

Linux

  1. Unzip and run ./<game>/<game>.
  2. Needs a desktop with OpenGL (Mesa is fine) and sound via ALSA or PulseAudio.

Privacy

No accounts, no ads, no tracking. Saves and high scores stay on your computer. Each download has a SHA-256 checksum so you can confirm it's the file we published.
